Код ASTRA и сайта

Собственный код предоставляется под лицензией MIT. Текст лицензии: LICENSE.txt. Исходный код ASTRA доступен на GitHub.

MIT распространяется на собственный код и материалы проекта, если для файла не указана другая лицензия, в той мере, в какой автор вправе предоставлять соответствующие права. Она не заменяет лицензии сторонних компонентов и не означает, что автор владеет Minecraft, чужими модами или брендами внешних сервисов. Права на товарные знаки лицензией MIT не предоставляются; нельзя выдавать чужие сборки за оригинальные выпуски проекта.

Компоненты, загружаемые отдельно

Minecraft, его библиотеки, Java и загрузчики получают собственные лицензии из своих источников. Моды и паки Modrinth/CurseForge не включены в exe ASTRA и не перелицензируются проектом.

authlib-injector используется для Ely.by как неизменённый Java Agent. Его лицензия — AGPLv3 или более поздняя версия с исключением AUTHLIB-INJECTOR. Исключение отдельно предусматривает загрузку в JVM как Java Agent; оно не отменяет остальных условий лицензии самого компонента. Исходники и условия, точный текст исключения. Компонент загружается с официального сервера, а не включается в exe ASTRA.

CustomSkinLoader, e4mc и моды настроек LAN устанавливаются отдельно при выборе соответствующих функций. Их лицензии и исходники указаны авторами на страницах проектов. При экспорте сборки с чужими файлами пользователь должен проверить право на их распространение; возможность экспорта сама по себе не даёт такого разрешения.
