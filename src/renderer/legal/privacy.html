Данные и конфиденциальность

Обновлено: 12 октября 2026. Проект: ASTRA. Проект поддерживается автором GitHub-репозитория Verskud из страны Украина. Текущий канал связи: https://github.com/Verskud/AstraLauncher/issues. ASTRA — название проекта, а не зарегистрированной компании.

Сайт

Сайт ASTRA — статическая страница с описанием лаунчера и ссылками на скачивание. В собственном коде сайта нет регистрации, платёжных форм, аналитики, рекламных пикселей, необязательных cookies или использования localStorage. Шрифты и изображения загружаются с этого же сайта. Сайт не требует согласия на рекламное отслеживание, поскольку оно здесь не используется.

Хостинг — GitHub Pages. При посещении GitHub получает технические сведения запроса, включая IP-адрес; GitHub сообщает, что IP-адреса посетителей Pages журналируются и сохраняются для обеспечения безопасности. Эти журналы не являются собственной аналитикой ASTRA, и оператор ASTRA не управляет сроками хранения GitHub. Подробнее: GitHub Privacy Statement и о GitHub Pages.

Ссылки на выпуски, исходники и внешние сервисы открывают другие сайты. Их правила обработки данных применяются при переходе. Файл лаунчера скачивается с GitHub Releases.

Что хранит лаунчер

Лаунчер хранит настройки интерфейса, имя локального профиля, список сборок, историю установленных файлов, адреса избранных серверов, миры, резервные копии и выбранные PNG-скины и плащи на устройстве. Основная папка данных Windows: %APPDATA%/AstraLauncher.

Для Ely.by сохраняются имя и UUID профиля, а токены сессии шифруются через Electron safeStorage средствами Windows. Пароль и код 2FA не записываются в файл настроек. Если пользователь самостоятельно настроил вход Microsoft, refresh token также сохраняется зашифрованно. Готовая интеграция Microsoft для обычных пользователей пока не предоставляется.

ASTRA не содержит собственной телеметрии, рекламного SDK или автоматической отправки журналов оператору проекта. Локальные журналы могут содержать имя игрока, пути к папкам, версии модов и ошибки игры. Перед отправкой журнала в поддержку проверь его и удали личные сведения. Наличие маскирования токенов в диагностике не заменяет такую проверку.

Запросы к внешним сервисам

По действию пользователя лаунчер взаимодействует с сервисами, необходимыми для выбранной функции:

  • Mojang/Microsoft и их CDN: списки версий, игровые файлы, библиотеки и среда Java; запросы имени/UUID и текстур при выборе публичных скинов; авторизация — только при настройке соответствующего входа.
  • Fabric, Quilt, Forge, NeoForge и Maven-репозитории: сведения о загрузчиках и загрузка библиотек.
  • Modrinth и CDN: поисковые запросы, версии проектов, зависимости и скачивание файлов. Сервис видит IP-адрес и технические параметры запроса.
  • Ely.by: email или имя входа, пароль и при необходимости код 2FA передаются по HTTPS на официальный authserver.ely.by для выбранного входа. Запросы профиля и текстур обращаются к сервисам Ely.by.
  • Официальный сервер authlib-injector: загрузка неизменённого Java Agent при использовании Ely.by.
  • Выбранные Minecraft-серверы: проверка доступности и игровой трафик. При подключении сервер обрабатывает сведения по своим правилам.
  • CurseForge: сейчас открывается официальный сайт в браузере; автоматического доступа лаунчера к каталогу CurseForge API для пользователей нет.

Сторонние сервисы получают эти запросы напрямую. Обработка ими данных регулируется их правилами. Установленные моды, включая CustomSkinLoader и e4mc, могут обращаться к другим сервисам в процессе игры; ознакомься с правилами выбранных модов. ASTRA не является оператором этих сервисов.

Обращения в поддержку

Сейчас обращения принимаются через GitHub Issues. Это публичный канал: сообщение, имя GitHub-профиля и приложенные файлы видны другим людям. Они используются для ответа, диагностики и ведения истории ошибок. Не размещай пароли, токены доступа, платёжные данные, email, адрес, личные документы или полные копии пользовательской папки. Отдельный приватный адрес поддержки пока не опубликован.

У сообщений GitHub Issues нет настроенного автоматического срока удаления: они остаются частью публичной истории проекта, пока не удалены доступными средствами GitHub. Закрытие issue не удаляет его содержимое. Автор может отредактировать свой комментарий; удаление issue, истории изменений и технических записей зависит от возможностей и правил GitHub. Локальные журналы не отправляются в Issues автоматически.

Управление и удаление

Аккаунт Ely.by можно отключить в лаунчере; сохранённый токен удаляется локально, а лаунчер пытается аннулировать сессию на сервисе. Локальные скины, сборки и резервные копии можно удалить соответствующими командами интерфейса. Удаление сборки удаляет также её миры.

Для полного удаления локальных данных сначала закрой лаунчер и игру, сохрани нужные миры и резервные копии в другой папке, затем удали %APPDATA%/AstraLauncher. Удаление exe само по себе не удаляет пользовательскую папку.

Если личные данные случайно попали в публичное обращение, отредактируй сообщение и попроси удалить его, указав ссылку на него без повторной публикации данных. Если в нём был токен или пароль, отзови токен или смени пароль: одно удаление сообщения не отменяет доступ. Для удаления платформенных записей обращайся также в GitHub Support. Запрос к ASTRA не удаляет данные у GitHub, Ely.by, Microsoft, Modrinth или операторов игровых серверов. Обязательные права и порядок их осуществления определяются применимым законодательством.
