# AstraLauncher workflow

- Keep the GitHub repository private unless the user explicitly asks to change visibility.
- After completing and checking project changes, commit the source changes and push them to `origin/main` so GitHub stays current.
- Do not commit `release/`, `node_modules/`, local credentials, tokens, or temporary build files.
- If a push is blocked by authentication or network access, report that the local changes are not yet on GitHub.
