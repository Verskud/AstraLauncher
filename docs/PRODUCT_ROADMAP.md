# Что взять из опыта других лаунчеров

Исследование по официальным страницам проектов. Это идеи для Astra, а не обещание уже готовых функций.

| Лаунчер | За что его выбирают | Что полезно Astra |
| --- | --- | --- |
| [Prism Launcher](https://www.prismlauncher.org/about/) | Изолированные сборки, установка модов с подбором версии и загрузчика, управление мирами, шейдерами и логами | Сделать сборку центром всех действий: установка, запуск, диагностика и резервные копии рядом |
| [GDLauncher](https://gdlauncher.com/docs/) | Установка версии и загрузчика, автоматический подбор Java, сборки из Modrinth и CurseForge, импорт | Свести создание сборки к нескольким понятным шагам, автоматически подбирать Java и зависимости |
| [ATLauncher](https://wiki.atlauncher.com/) | Готовые и собственные сборки | Добавить простой мастер собственной сборки и понятную публикацию подборок |

## Порядок реализации

1. **Игровой запуск:** проверка владения Minecraft через Microsoft/Xbox/Minecraft Services, загрузка клиента и ресурсов из официальных манифестов, проверка хешей, запуск из отдельной папки сборки, выбор подходящей Java, журнал ошибок. Пока этого нет, кнопка запуска должна прямо сообщать об ограничении.
2. **Настоящая установка модов:** выбирать файл под конкретные версию Minecraft и загрузчик; показывать несовместимости и обязательные зависимости; скачивать в папку сборки с проверкой хеша. Каталог и отдельная загрузка файла уже есть.
3. **Импорт и перенос:** `.mrpack`, профиль Prism, экспорт собственной сборки; предварительный просмотр файлов и источников перед установкой.
4. **Удобство:** обновление модов с просмотром изменений, резервные копии миров, открытие папки сборки, журнал запуска и понятные сообщения об ошибках.
5. **Создание сообщества:** тематические готовые подборки, которые можно установить и обновлять одним действием; прозрачные правила для платных авторских сборок и рекламы.

Для версий Minecraft используется [официальный манифест Mojang](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json). Выбор версии в профиле уже доступен, включая снапшоты и исторические версии. Установка и запуск выбранной версии идут отдельным этапом. Наличие версии Minecraft не означает наличия Fabric или Forge для неё.
