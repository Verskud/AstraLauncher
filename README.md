# ASTRA Launcher 0.9.20

Предварительная версия лаунчера Minecraft Java Edition для Windows x64. Готовый файл: `release/AstraLauncher-0.9.20.exe`.

## Что работает

- Закреплённая сборкой версия Forge/NeoForge выбирается точно, включая исправление неверного кэша старых версий ASTRA. Для Forge 1.20.1 известные Universal-файлы CustomSkinLoader 15.0–15.1 заменяются на совместимый ForgeV2 14.28 с сохранением оригиналов в `.astra-repairs` внутри сборки. При падении игры доступны детали ошибки и открытие журнала.
- Установка сборок Modrinth: архив и файлы пишутся потоком на диск с проверкой размера и SHA-512. До шести файлов скачиваются одновременно; файлы от 2 МБ с CDN Modrinth загружаются четырьмя параллельными частями. Если сервер не поддерживает Range, используется обычная загрузка. Временные сетевые ошибки повторяются до трёх попыток. Окно показывает этап, объём и скорость скачивания. Ожидание каталога ограничено 30 секундами, отсутствие данных при скачивании — 30 секундами на попытку.
- Выбор Fabric, Quilt и NeoForge доступен для календарных релизов Minecraft 26.x и новее. Интерфейс и проверка перед запуском используют одинаковые границы версий; наличие конкретного загрузчика проверяется по его официальному каталогу при установке.
- Плавное появление экранов и окон, отклик карточек и кнопок. Анимации можно выключить; настройка уменьшения движения Windows также учитывается. Тема «Стекло» использует прозрачные панели и нативное размытие на Windows 11 22H2 и новее, с тёмной подложкой на старых системах. Девять обложек сборок в одном блочном стиле с выбором по миниатюрам. Поиск каталога открывается сочетанием Ctrl+K или клавишей `/`.
- В настройках внешнего вида можно установить собственный TTF, OTF, WOFF или WOFF2 размером до 20 МБ и в любой момент вернуть стандартный Manrope. Выбранный файл копируется в локальную папку данных ASTRA.

- Создание отдельных сборок Vanilla, Fabric, Quilt, Forge и NeoForge. Для релизов загрузчик устанавливается при первом запуске из официального источника. Fabric и Quilt доступны с Minecraft 1.14, NeoForge — с 1.20.2; для 1.12.2 выбирай Forge или Vanilla. Загрузчик существующей сборки можно изменить в её параметрах без удаления миров.
- Загрузка Minecraft из манифеста Mojang с проверкой SHA-1, прогрессом, повторной проверкой и отменой. Отмена с подтверждением удаляет файлы выбранной версии, сохраняя общие файлы других версий.
- Автоматическая загрузка подходящей Java из официального каталога Mojang, отдельные папки для миров, настроек и модов каждой сборки, запуск игры кнопкой «Играть». Проверен тестовый запуск Minecraft 1.21.1 с Vanilla, Fabric, Quilt, Forge и NeoForge, а также Minecraft 1.12.2 с Vanilla и Forge.
- Локальный профиль для одиночной игры. Microsoft device code flow с обменом токенов Xbox и проверкой Minecraft Java Edition доступен после добавления собственного Client ID приложения. Локальный профиль не даёт доступа к серверам, которые требуют официальную авторизацию.
- Каталог Modrinth и CurseForge. При открытии каталога из сборки она выбирается целью установки; при обычном открытии каталога выбирается первая совместимая сборка. Папка «Загрузки» остаётся отдельным выбором. Для модов Modrinth загружаются обязательные зависимости. Для Fabric/Quilt проверяются требования версий в `fabric.mod.json`: несовместимый файл отклоняется до установки, а старые копии того же проекта заменяются. CurseForge требует собственный API ключ. Ключи и refresh token Microsoft хранятся зашифрованно через Electron `safeStorage`.
- Файлы каталога до 1 ГБ скачиваются потоком с проверкой фактического размера ответа; это позволяет загружать крупные сборки, HD ресурспаки и шейдеры.
- При загрузке сборок таймаут отсчитывается от последнего полученного блока данных, поэтому длительная загрузка не обрывается через две минуты. Ресурсы Minecraft скачиваются в 12 потоков через ограниченный пул HTTPS соединений с keep-alive.
- Списки модов, шейдеров и ресурспаков читаются из папки выбранной сборки; установленные файлы можно удалить с подтверждением. Основные экраны, окна создания и настройки сборок, каталог и сообщения доступны на 12 вариантах языка. Есть темы, обложки и системные кнопки окна.
- Сборки Modrinth устанавливаются из `.mrpack` в отдельные папки `%APPDATA%/AstraLauncher/instances/<ID>`; свои `.mrpack` можно импортировать через «Мои сборки». Моды и настройки проверяются перед добавлением в библиотеку; при ошибке или отмене неполная сборка удаляется. Папку можно открыть из параметров сборки. Для игр с годовой нумерацией (например, 26.3) поддержан выбор загрузчика по новому номеру версии.
- Для Fresh Animations лаунчер предлагает установить EMF с обязательной зависимостью ETF. Ресурспак нужно включить в настройках самой игры.
- В разделе «Миры» можно создать, просмотреть, восстановить и удалить локальные резервные копии миров сборки. При восстановлении текущее состояние сначала сохраняется отдельной защитной копией. В настройках Minecraft можно включить автокопию перед запуском и выбрать хранение 3, 5 или 10 последних автокопий. Ручные копии автоматически не удаляются. Копии хранятся в папке данных Astra отдельно от игровых файлов.

## Серверы и скины

В разделе «Серверы» можно сохранить до 50 избранных адресов Minecraft Java, изменить их и скопировать адрес. Статус, число игроков, MOTD и пинг проверяются напрямую через TCP с поддержкой DNS SRV. Пока страница открыта, список обновляется раз в минуту. Старый протокол серверов до Minecraft 1.7 и Bedrock не поддерживаются; блокировка проверки сервером может отображаться как недоступность.

В «Аккаунтах» есть 2D-предпросмотр скина спереди и сзади и плаща со спины. Источник — локальные PNG, публичные текстуры Mojang по имени игрока или Ely.by. PNG хранятся в `%APPDATA%/AstraLauncher/player-appearance`; размеры скина 64×64/64×32, плаща 64×32. CustomSkinLoader устанавливается с официального Modrinth только в совместимую выбранную сборку с загрузчиком. При следующих запусках настройки и локальные текстуры обновляются автоматически. Пользовательские записи конфигурации CustomSkinLoader сохраняются. Для просмотра альтернативных скинов другими игроками нужна совместимая система скинов. Локальные PNG не загружаются в Microsoft-аккаунт.

Проверены сетевой протокол на локальном тестовом сервере, изолированные файлы конфигурации, интерфейс на 12 языках и 900×560, реальный скин Ely.by и установка CustomSkinLoader 15.1 для Fabric 1.21.1. В этой версии не проверялось отображение скина внутри запущенной Minecraft.

## Управление сборками и Ely.by (0.9.16)

- Моды временно выключаются переименованием в `.jar.disabled` и остаются в списке. Загрузчик игры игнорирует такие файлы. Проверка обновлений определяет активные JAR по SHA-512 через официальный API Modrinth, с фильтром версии Minecraft, загрузчика и стабильного выпуска. Неизвестные и выключенные файлы не обновляются. Каждое обновление выполняется отдельно в промежуточной папке; ошибка загрузки не меняет оригинал. Требования Fabric/Quilt проверяются существующим механизмом установки зависимостей; для Forge/NeoForge полную совместимость по-прежнему проверяет игра.
- Копирование сборки создаёт независимые файлы и новый профиль; миры можно включить или исключить. Экспорт ASTRA ZIP переносит файлы модов, шейдеров, ресурспаков и настроек с необязательными мирами. ZIP импортируется обратно через «Мои сборки» или «Импорт». Общие Minecraft/Java, логи, служебные файлы авторизации и скриншоты не экспортируются. Максимум ZIP32 — менее 4 ГБ; отдельный файл — до 1 ГБ. JSON-импорт старых профилей сохранён.
- В сборке есть вкладка скриншотов из `screenshots`: миниатюры, открытие изображения в системной программе и открытие папки. Изображения больше 32 МБ доступны для открытия, но не получают миниатюры.
- Аккаунты показывают выбранный способ запуска: локальный, Ely.by или ранее подключённый Microsoft. Вход Ely.by реализован через официальный `authserver.ely.by`, с email, паролем и кодом 2FA. Пароль не сохраняется; токен шифруется Windows safeStorage и обновляется перед запуском. Для Ely.by автоматически скачивается официальный authlib-injector с проверкой SHA-256, начиная с Minecraft 1.7.2. Такие аккаунты подходят для серверов с поддержкой Ely.by; Microsoft-серверы требуют соответствующего Microsoft-аккаунта. Собственная регистрация Microsoft приложения отложена.
- Локальные PNG принадлежат локальному профилю; скин подключённого аккаунта загружается по его имени. Управление скином Ely.by открывает сайт Ely.by. Цвет значка уведомлений и других значков в диалогах следует текущему акценту темы.

Проверены отключение модов, независимость копий, ZIP-экспорт/импорт, сохранность модов при ошибке обновления, логика 2FA/обновления/отмены входа на тестовом API, экран аккаунтов и новые кнопки на 12 языках. Реальный API обновлений Modrinth и загрузка authlib-injector проверены. Вход с настоящими учётными данными Ely.by и игровая сессия Ely.by ещё не проверены.

## Ограничения предварительной версии

- CurseForge ZIP и профили Prism пока не импортируются. Поддерживается собственный ASTRA ZIP и Modrinth .mrpack.
- Зависимости CurseForge нужно установить отдельно. Если обязательная зависимость Modrinth недоступна, установка прервётся с сообщением. Для Forge/NeoForge пока нет полной проверки требований внутри JAR; окончательную совместимость проверяет загрузчик игры.
- Для отображения шейдеров в игре требуется совместимый мод, например Iris или Oculus. Сам файл шейдера помещается в `shaderpacks`.
- Часть подборок всё ещё демонстрационные; они помечены как макет. Копии миров локальные и не загружаются в облако.
- Microsoft вход требует Client ID зарегистрированного приложения, которого у проекта пока нет. Проверка лицензионного запуска с реальным аккаунтом ещё не выполнена.
- Исторические версии и снапшоты выбираются как Vanilla. Реальный запуск проверен на Minecraft 1.21.1; совместимость всех старых версий не гарантируется.

## Структура

```text
src/main/minecraft-install.cjs  Загрузка и проверка Minecraft
src/main/game-java.cjs          Поиск и установка Java от Mojang
src/main/game-loader.cjs        Установка Fabric, Quilt, Forge, NeoForge
src/main/game-launch.cjs        Параметры запуска и отдельные игровые папки
src/main/world-backups.cjs      Локальные копии и восстановление миров
src/main/download.cjs           Файлы Modrinth и CurseForge
src/main/modpack.cjs            Импорт и установка сборок Modrinth
src/main/zip-reader.cjs         Проверка и чтение .mrpack
src/main/microsoft.cjs          Microsoft, Xbox, Minecraft authentication
src/preload/                    Ограниченный IPC мост
src/renderer/                   Интерфейс, языки, темы и локальные сборки
tools/check.mjs                 Проверка синтаксиса
release/                        Portable exe, не хранится в Git
```

## Разработка

```sh
pnpm install --frozen-lockfile
pnpm start
node tools/check.mjs
pnpm build
```

Логотип предоставлен пользователем. Шрифт Manrope распространяется по OFL: `src/renderer/assets/fonts/OFL.txt`.
