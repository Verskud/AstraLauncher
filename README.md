# AstraLauncher — Windows Desktop 0.8.1

Предварительная версия лаунчера Minecraft для Windows x64. Запуск: `release/AstraLauncher-0.8.1.exe` без установки Node.js или браузера.

## Что работает

- Каталог модов, сборок, шейдеров и ресурспаков из официального Modrinth API: поиск, страницы, актуальная статистика.
- Подключение CurseForge API в «Настройки → Общие → Подключения». Нужен собственный API ключ. Ключ хранится локально в зашифрованном виде через Electron `safeStorage`.
- Скачивание выбранного файла из Modrinth и, после добавления ключа, CurseForge в системную папку `Загрузки/AstraLauncher`. Для Modrinth проверяется SHA-512, если хеш получен от API.
- На экране загрузок можно открыть папку с файлами и убрать запись из истории, не удаляя скачанный файл. Если файл перемещён или удалён вручную, лаунчер сообщает, что его больше нет.
- Подключение личного аккаунта Microsoft через официальный device code flow после указания Client ID своего зарегистрированного приложения. Пароль вводится только на сайте Microsoft. Refresh token хранится через `safeStorage`.
- Локальные профили сборок и настройки интерфейса.
- Выбор версии Minecraft Java Edition из официального манифеста Mojang: релизы, снапшоты, исторические бета и альфа. Есть поиск, фильтр по типу и локально сохранённый список для работы без сети. В комплекте — снимок каталога на 918 версий от 10 октября 2026 года; при подключении к интернету список обновляется.
- На экране выбранной сборки можно скачать официальные файлы версии Minecraft: клиент, библиотеки Windows и ресурсы. Файлы сохраняются в пользовательских данных приложения в папке `minecraft`, проверяются по SHA-1 из манифеста Mojang; повторная загрузка использует целые файлы и исправляет повреждённые. Есть прогресс и отмена с предупреждением: при подтверждении файлы выбранной версии удаляются, а общие файлы других установленных версий сохраняются. Для первой загрузки нужен интернет; объём ресурсов зависит от версии и может составлять сотни мегабайт.
- Выбор языка основных экранов и настроек: русский, английский, немецкий, французский, испанский, корейский, японский, китайский (упрощённая запись), мандаринский (традиционная запись), арабский, швейцарский немецкий и норвежский букмол. Названия языков показаны на родном языке; арабский интерфейс использует направление справа налево.
- Двенадцать тем: Полночь, Графит, Аметист, Океан, Лес, Янтарь, Иней, Роза, Медь, Аврора, Сланец и Песок. Для каждой доступен цвет темы или монохромный акцент. Язык и оформление сохраняются локально.
- Девять обложек сборки с предпросмотром при создании и редактировании.
- Системные кнопки окна Windows справа в шапке; цвет панели меняется вместе с темой.

## Что ещё требуется

Вход Microsoft сейчас подтверждает личность, но не проверяет владение Minecraft. Скачивание версии не означает, что игра уже запускается: установка Java и загрузчиков Fabric/Forge, запуск игры, установка модов в профиль и игра на официальных серверах пока не реализованы. Для снапшотов и исторических версий доступен только профиль Vanilla. Для релизов можно отметить Fabric или Forge, но их наличие для конкретного релиза ещё не проверяется. Скачанные моды с обязательными зависимостями требуют их отдельной загрузки. Эти ограничения показаны в интерфейсе.

Для CurseForge нужен API ключ: [официальная документация](https://docs.curseforge.com/rest-api/). Для входа Microsoft нужен Application (client) ID приложения, разрешающего личные аккаунты и public client flows: [документация Microsoft](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-device-code).

## Структура

```text
src/main/                 Окно, официальный каталог, загрузки, настройки, Microsoft OAuth
src/main/versions.cjs     Каталог версий Minecraft и локальный кеш
src/main/minecraft-install.cjs Установщик официальных файлов Minecraft
src/main/data/            Снимок официального каталога для запуска без сети
src/preload/              Ограниченный IPC мост
src/renderer/             Интерфейс, стили, изображения и локальный профиль
src/renderer/core/live.js Живой каталог и подключение аккаунтов
src/renderer/core/personalization.js Языки, переводы основных экранов и темы
src/renderer/core/versions.js Поиск и выбор версии при создании сборки
docs/PRODUCT_ROADMAP.md   Исследование других лаунчеров и порядок следующих работ
tools/check.mjs           Проверка синтаксиса
tools/update-versions.mjs Обновление комплектного снимка каталога Mojang
electron-builder.yml      Portable сборка Windows
release/AstraLauncher-0.8.1.exe Готовое приложение
```

## Разработка

```sh
pnpm install --frozen-lockfile
pnpm start
node tools/check.mjs
node tools/test-minecraft-install.cjs
node_modules/.bin/electron.cmd tools/test-minecraft-ui.cjs
pnpm build
```

Логотип предоставлен пользователем. Шрифт Manrope распространяется по OFL: `src/renderer/assets/fonts/OFL.txt`.
