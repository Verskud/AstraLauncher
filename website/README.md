# Сайт ASTRA

Статический сайт без регистрации, платежей, cookies, аналитики и сторонних CDN. Публичный адрес: https://verskud.github.io/AstraLauncher/

Исходники сайта хранятся в основном репозитории в папке website/. Локальная рабочая копия сайта находится отдельно по выбранному владельцем пути. Основной репозиторий открыт по явному разрешению владельца; лицензия собственного кода и сайта — MIT.

## Изменения

- Тексты и оформление: src/index.html, src/style.css, src/site.js.
- Документы: docs/privacy.md, docs/terms.md, docs/licenses.md.
- Версия и ссылки: site.config.json. Указывайте только реально опубликованный выпуск.
- Сборка без зависимостей: node tools/build.mjs.
- Предпросмотр: node tools/serve.mjs, http://127.0.0.1:4173.
- GitHub Pages обновляется workflow .github/workflows/pages.yml после push в main.
- Файлы exe находятся в GitHub Releases, а не в Git и не в файлах сайта.

Текущий канал поддержки — публичные GitHub Issues. Личный email владельца не публикуется. Приватный email можно добавить позже вместе с обновлением политики данных. 

## Проверка

Проверены страницы, локальные ссылки, ширины 320–1440px, клавиатура, уменьшение движения и отсутствие cookies/хранилищ/сторонних запросов. docs/legal-review.md описывает пределы правовой подготовки; документы не являются гарантией отсутствия претензий. Уведомления Electron/Chromium и лицензия Manrope сохранены.

.openai/hosting.json в отдельной локальной копии связывает её с частным Sites-предпросмотром; этот файл не нужен для GitHub Pages.
