## Существенные ограничения

- Minecraft не входит в дистрибутив. Не продавать право на игру, не обещать бесплатную лицензию. Наличие локального профиля и Ely.by не подтверждает владение Minecraft. Публичное распространение такого лаунчера и конкретный способ подготовки игры требуют оценки в контексте Minecraft EULA и политики Microsoft; одна подпись в футере не решает все вопросы.
- Minecraft Usage Guidelines требуют ясно обозначать отсутствие официальной связи и одобрения. Бесплатные публичные проекты также подпадают под их правила использования бренда.
- Сторонние JAR, runtime Java и моды не получают лицензию ASTRA. Программа скачивает их отдельно из источников. При экспорте/передаче сборки проверять лицензии включённых файлов. authlib-injector имеет AGPLv3+ с отдельным исключением для Java Agent; не заменять эту лицензию собственным MIT/GPL.
- Код создавался с помощью ИИ. Лицензировать можно только права, которыми действительно располагает владелец; авторское право на отдельные автоматически созданные фрагменты и изображения зависит от юрисдикции. Не заявлять исключительные права на чужие элементы или гарантированную охраноспособность результата ИИ.
- Для заявленного open source нужны доступные исходники и выбранная лицензия. Владелец выбрал MIT и явно разрешил открыть основной репозиторий с историей после проверки.
- Проверить дистрибутив на отсутствие пользовательских миров, токенов, настроек аккаунтов, локальных журналов и закрытых API-ключей. При раскрытии репозитория отдельно проверить всю историю Git; .gitignore не удаляет уже попавшие туда секреты.
- Цифровая подпись Windows требует отдельного решения. Если подписи издателя нет, нельзя обещать отсутствие предупреждений SmartScreen или писать, что сертификат проверен. SHA-256 подтверждает целостность, а не безопасность программы.
