## Компоненты, загружаемые отдельно

Minecraft, его библиотеки, Java и загрузчики получают собственные лицензии из своих источников. Моды и паки Modrinth/CurseForge не включены в exe ASTRA и не перелицензируются проектом.

authlib-injector используется для Ely.by как неизменённый Java Agent. Его лицензия — AGPLv3 или более поздняя версия с исключением AUTHLIB-INJECTOR. Исключение отдельно предусматривает загрузку в JVM как Java Agent; оно не отменяет остальных условий лицензии самого компонента. [Исходники и условия](https://github.com/yushijinhun/authlib-injector), [точный текст исключения](https://github.com/yushijinhun/authlib-injector/blob/develop/AGPLv3-with-authlib-injector-exception.txt). Компонент загружается с официального сервера, а не включается в exe ASTRA.

CustomSkinLoader, e4mc и моды настроек LAN устанавливаются отдельно при выборе соответствующих функций. Их лицензии и исходники указаны авторами на страницах проектов. При экспорте сборки с чужими файлами пользователь должен проверить право на их распространение; возможность экспорта сама по себе не даёт такого разрешения.
